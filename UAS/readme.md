Projek Sistem POS Media Corner
Sistem POS Media Corner merupakan sistem Point of Sale berbasis Java yang dirancang untuk mendukung operasional toko ATK Media Corner. Sistem ini menyediakan fitur pengelolaan produk seperti barang dan jasa, pengelolaan stok, transaksi penjualan, proses return barang, serta pencatatan pendapatan bersih toko. Dengan adanya sistem ini, proses pencatatan transaksi menjadi lebih terstruktur, cepat, dan akurat dibandingkan pencatatan manual. Adapun instruksi penggunaanya yaitu:
Jalankan program SistemPOSMediaCorner.
Pada Menu Utama, pilih:
1. Transaksi Baru untuk melakukan penjualan barang atau jasa.
2. Return Barang untuk memproses pengembalian barang dari transaksi sebelumnya.
3. Lihat Pendapatan Bersih Toko untuk melihat total pendapatan yang telah diperoleh.
4. Lihat Stok untuk melihat ketersediaan stok barang.
5. Keluar untuk menutup program.
Pilih barang dan masukkan jumlah yang ingin dibeli atau direturn.
Setelah pembayaran berhasil dilakukan, sistem akan menampilkan struk transaksi.
Gunakan menu return jika terdapat barang yang dikembalikan oleh pelanggan.
